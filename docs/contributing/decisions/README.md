# Normative contracts

<!-- cockpit:verified version=0.0.0 -->

These contracts define contributor-facing behavior that crosses several implementation
owners. They supplement the architecture and policy documentation.

- [Operator paths](operator-paths.md) defines the direct-work and accepted-work-order paths.
- [Installed capabilities](installed-capabilities.md) defines observation-dependent execution,
  generated-file ownership, and framework/overlay boundaries.

Contracts are updated in place when required behavior changes. Record user-visible migrations
in [CHANGELOG.md](../../../CHANGELOG.md).
