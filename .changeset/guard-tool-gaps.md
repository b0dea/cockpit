The guard refuses or asks for more ways to reach a secret, a protected branch or the person's own tools, and admits more ordinary development.

- Refused: `npm run env` (and yarn's and pnpm's), `make -p`, awk reading `ENVIRON`, `declare -p`/`typeset -p` of a secret's name and `git var -l`; `gh pr merge --admin`, `gh repo sync --force`, `gh repo delete` and `gh repo edit` of the default branch, visibility or merge settings; `npm`/`pnpm`/`yarn config set`, `delete` and `edit`, global installs, `npm link`, `go install`, `go env -w`, `cargo install`, `uv tool install`, `pip install --user`, `pipx install`, `gh config set`, `gh alias set` and `gh extension install`; a fetch whose refspec writes a protected branch and `git rebase --onto x y <protected>`; bundled and abbreviated force pushes such as `-uf` and `--forc`; an environment file or secrets path named to any known tool, uploads included, which used to ask; and the login files of opencode, Claude Code (`~/.claude.json`), Vercel, Wrangler, Stripe, Supabase, Fly, Netlify, Firebase, sentry-cli, hub and doctl, and shell histories.
- Asks: `gh pr merge` without `--admin` and other `gh repo` edits; `npm config set --location=project`; installs from a URL or Git source with pip, uv, npm, pnpm, yarn and bun; awk that prints or pipes to a file; interpreters given code after other options, from a data or remote URL, or on standard input; `make --eval`/`-E`/`-f -`, `go -exec`/`-toolexec`/`-vettool`, `rsync -e`, `scp -S`/`-F`/`-o ProxyCommand`, `zip -TT`; `git -c trailer.<name>.cmd` is refused like the other program keys; a word joining a variable to text, and any variable a reading, copying or uploading tool is given; `pnpm <word>` and `bun run <word>` when the nearest package.json declares no such script, judged as the program instead.
- Allowed: `git grep`, `git blame` and `git show <rev>:<path>`; `grep -C3`; `sed` substitutions and pattern addresses; `cat > file <<'EOF'`; `tar -czf`, `-xzf`, `-tzf` and dashless clusters; a known tool given a directory that holds guard files, such as `npx eslint .` at the cockpit root; `lsof`, `kill` and `pkill`, `gofmt`, `golangci-lint`, `rustup show`, `bundle exec`, `rspec`, `rake` and `pre-commit run`.
- Messages name the next step: the allow default's reading-command ask names the forms it reads, Docker Compose points to `cockpit up`, `logs` and `ps`, unsupported writer forms and unclassified guard-file operands name what to run instead, an unknown push option is named, copying the installed package is no longer called a cockpit command, and a here-string says to pipe the text.
