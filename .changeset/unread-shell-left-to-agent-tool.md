Shell the guard does not read, such as `case`, `[[ … ]]`, `eval`, arithmetic over a name or `${name##pattern}`, no longer forces a prompt. When its words name nothing on the deny list, the guard gives no answer, so Claude Code and Codex decide as they would without it; Codex no longer refuses these calls. Shell text a session, job or terminal runs (`tmux`, `screen`, `at`, `crontab`, `systemd-run`) still asks, because it can run after the call ends, as does unread text with a `&`, an environment dump or a substituted download.
