# Changesets

<!-- cockpit:verified version=0.0.0 -->

Release notes are written by the person making the change, when they make it — run
`npx changeset`, pick the bump, and write the entry for a reader deciding whether to
upgrade (O1.6). `changeset version` folds pending entries into CHANGELOG.md at release.
`access` stays `restricted` until the operator explicitly makes the package public.
