`work record` refuses `resolve-gap` and `decision` events, which speak for a person; a person records them with the new interactive `work answer`, which shows the open question or decision and records it as the operator after they type the displayed digest. The guard does not run `work answer` for an agent. Work-command refusals for an unparseable intent, event, programme ledger or record file name the file, the line and column when known, and the expected shape instead of quoting its bytes.
