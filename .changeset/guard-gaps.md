The guard now judges a recursive copy (`cp -R`, `-r` or `-a`) as it judges `rsync`, instead of refusing it as a form it does not model. Each source is read as a tree, so copying one that holds an environment file, a `.secrets` directory or a credential store is refused, and each destination is a write, so copying into a guard control, the installed cockpit or a related checkout is refused. Copying a tree that holds guard files or a checkout's `.git`, such as `cp -R . build/snapshot`, asks, as `rsync` does. A call may now end in one command that makes or copies links, as in `mkdir -p build && cp -r src build/out`, since nothing after it can follow them. A glob source such as `src/*` is now walked as its directory for `cp`, `rsync` and recursive searches alike, where the walk used to find nothing. A credential store's directory spelled with a trailing slash or a glob after it, as in `rsync -a "$X/.aws/" build/` or `glob('.aws/*')` in inline code, is now refused as the directory itself. The one command a tmux session, window or pane opens, or that `screen -dm` starts, is now judged as `sh -c` text in the background, so `tmux new-session -d 'npm run dev'` runs while one naming a secret or guard file is refused; `respawn-pane`, `-k` and a session started with a changed environment still ask, and so does setting `SCREENRC`, `SYSSCREENRC`, `SCREENDIR`, `TMUX` or `TMUX_TMPDIR`. Other shell text that a tmux or screen session (a tmux format's `#(…)` and `detach -E` included), an `at` or `batch` job, an installed crontab (read from standard input too), `systemd-run`, a terminal's command, `open --args` or osascript's `do shell script` runs is now judged as shell the guard does not read: refused when it names a secret, a credential or a guard file, and otherwise asked, where before it ran unread. A recursive `cp`, `rsync`, `ditto` or `scp` of a tree holding an agent tool's settings, a guard directory, a repository, Git hooks or direnv's `.envrc` now asks, naming what it found, and so does one whose tree the guard cannot walk to the end. `:`, `true` and a bare `wait` after the command that makes a link no longer refuse the call, unless the call can make one run a program through `enable`, `disable`, `hash`, `builtin`, an alias, zsh's function loading or a new PATH or FPATH. Restoring a `[guards] related_checkouts` entry that is the cockpit's own checkout, or holds it, no longer counts as widening what agents may do in that checkout, since the guard drops such an entry there. Homebrew's g-prefixed GNU tools, such as `grm`, `gcp`, `gsed`, `gtar`, `gtime` and `gmake`, are now judged as the commands they are, where before `grm -rf .cockpit/guards` ran as an unknown program.
