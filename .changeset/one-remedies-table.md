The installed guide keeps one table of diagnostic remedies, at the end of `docs/troubleshooting.md`: a code is listed there when every place that raises it gives the same fix, or a troubleshooting section covers it, and every other code's message is its guidance. The CLI reference no longer lists codes under each command, and the per-family remedies in `docs/environment.md` are gone. Moving an existing setup over to cockpit is now a section of `docs/getting-started.md`, and the package no longer ships the reference-page generator.
